# JS test harness for the report front end (dev-only)

`downstream/assets/report.js` has no automated tests of its own; this directory
is that harness. It is **dev-only**: nothing here ships in the report, the exe,
or the package runtime dependencies (PyYAML stays the only one).

## What it does

The harness loads `fixture.html` — a real self-contained report generated by
`make_fixture.py` through the actual downstream pipeline — inside
[jsdom](https://github.com/jsdom/jsdom), then runs the same inlined
`report.js` source a browser would execute. Two loaders exist in
`lib/harness.mjs`:

- `loadReport({ data })` — evaluates the report source against the fixture DOM
  with swapped-in payload data (one sample, zero comparisons, hostile names…).
- `loadReportRaw({ html })` — runs the fixture HTML exactly as a browser would
  (`runScripts: "dangerously"`), exercising the real HTML tokenisation of the
  shipped escaping.

Both collect uncaught page errors and `console.error` calls via a jsdom
VirtualConsole; tests assert the list stays empty.

## Test files

- `test/sections.test.mjs` — every section renderer against the payload shapes
  the audit brief calls out: the fixture baseline, zero comparisons, one
  sample, ratio (isoDTB) data, 10,000 features × 50 samples, all p-values
  missing, and the dark/light theme toggle.
- `test/escaping.test.mjs` — gene/sample/condition/description names containing
  `<`, `&`, quotes and `<script>` through every dynamic-HTML sink (table,
  tiles, detail panel, the `showTip` tooltip, CSV export), plus the skipped
  F-01 regression (a `<!--` in the data breaks the shipped script-tag
  escaping; the test switches on when that is fixed).

## Running

```bash
cd ionomos/tests/js
npm install          # jsdom only (dev dependency; committed package-lock.json)
npm test             # or: node --test test/
```

CI (`.github/workflows/tests.yml`) runs `npm ci` and `npm test` on both Ubuntu
and Windows alongside the Python suite.

## Keeping the fixture current

`tests/test_js_fixture_sync.py` fails when `fixture.html` no longer contains
the current `report.js`/`report.css` or the payload loses a key report.js
reads. After changing the report front end or `report.py`, regenerate:

```bash
cd ionomos && .venv/bin/python tests/js/make_fixture.py
```

## jsdom gaps the harness bridges

jsdom has no layout engine and no canvas. `lib/harness.mjs` stubs, via
`beforeParse` (before any script runs):

- `canvas.getContext` — a no-op Proxy accepting any 2d-context call;
- `window.matchMedia` — `matches: false`, inert listeners;
- `Element.prototype.getBoundingClientRect` — returns the element's own
  `width`/`height` attributes (the SVG roots carry them); without this the
  volcano's hover maths divides by zero and no tooltip ever fires;
- `scrollIntoView`, `URL.createObjectURL` (blobs are captured for inspection).
